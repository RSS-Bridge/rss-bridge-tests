Firefox Desktop Release Notes

Firefox Desktop 160.0.1 Release Note

2026-11-17 00:00:00

Fixed

  • Fixed thin lines in PDFs printing as thick black boxes on some printers on Windows. (Bug 2091728)

  • Fixed PDFs, web page graphics, and WebGL content appearing blank or broken on Macs with AMD graphics, such as black cells in Google Sheets. (Bug 2091596)

  • Fixed incorrect colors in WebGL and canvas content, such as games and Google Meet backgrounds, on some Linux systems using Wayland. (Bug 2089043)

  • Fixed links on some sites, such as the Google Store, taking a very long time to load. (Bug 2087787)

  • Fixed tabs crashing on some sites, most notably ChatGPT. (Bug 2088486)

  • Fixed WebTransport connections being unable to send datagrams after a site sent many in quick succession. (Bug 2092532)

  • Fixed trackpad and mouse swipes sometimes scrolling the page when a site had blocked scrolling. (Bug 2086786)

  • Various security fixes.
